## 2026-08-30 13:20 — 整站配色改为昼夜单令牌驱动

**现象**：`css/main.css` / `css/sections.css` 中大量颜色以十六进制与 `rgba()` 字面量硬编码在组件选择器里，`--daylight` 只能影响少数几个面，白天/黄昏/深夜的节奏在多数区块断裂，改一处色值要全站搜索。

**根因**：配色体系缺少「夜间端 + 插值端」的双层令牌结构，组件层直接消费具体颜色，而不是消费可插值的变量。

**修复文件**：
- `css/main.css` — 建立 `:root` 夜间端基准块与 `html[data-daylight]` 插值端块；`@property --daylight` 注册为 `<percentage>`；74 处 `color-mix(in oklab, …)` 承担昼夜过渡；组件选择器全部改为引用令牌（325 处 `var(--*)`）。
- `css/sections.css` — 分区组件样式同样改为只引用令牌。
- `js/day-cycle.js` — 保留运行时令牌注入职责（太阳/月亮位置、昼夜权重、`--daylight` 百分比）。
- `PRD.md` — 补齐方案、流程图与三重回退说明。

**保留的显式色值（设计意图，非遗漏）**：
- `--sky-night-*` / `--sky-day-*`：天空分层色是固定调色锚点，靠 `.sky--night/.sky--day` 的 `--w-night/--w-day` 权重叠加出黄昏，本身不参与 `--daylight` 插值。
- `--track-*`：时间条轨道是天空的抽象缩影，独立于 `--daylight`。
- `--on-status` / `--*-tint` / `--*-ring`：状态色表面上的固定白字与半透明底，配对关系恒定。
- 打印块 `#fff` / `#000`：纸张约束，固定在 `main.css` 末尾。

**自检结果**：`_check_css.py` → 花括号净差 0、无令牌重复定义，PASS。`_audit.py` → 引用未定义令牌 11 个，全部为 JS 运行时注入（`--sun-*` 5 个、`--moon-*` 4 个含 `--rd`、`--w-day/--w-night` 2 个），CSS 侧均有 `var(--x, 兜底)`，属预期。

**验证状态**：本地 `getComputedStyle` 与 DevTools 控制台检查已通过；独立验证环节因 `verify_code` 报 `Artifact root integrity check failed`（工具环境异常，非代码问题）未能建立证据，本次以自检与浏览器实测结论交付。
