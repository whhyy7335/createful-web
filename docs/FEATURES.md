## 昼夜单一令牌驱动配色系统

- 首次添加：2026-08-30 12:40
- 实际状态时间：2026-08-30 13:20
- 状态：已实现
- 说明：整站颜色由 `--daylight`（0% 深夜 → 100% 正午）一个变量驱动。`:root` 存夜间端基准值，`html[data-daylight]` 块用 `color-mix(in oklab, …)` 声明插值端，`@property` 把 `--daylight` 注册为 `<percentage>` 以获得连续插值。组件选择器不再写死颜色，只引用令牌。
- 回退路径：无 JS 时 `<html>` 不带 `data-daylight`，覆盖块不匹配，整站停在夜间端；`prefers-reduced-motion` 下关闭过渡，颜色仍跟时间走。
